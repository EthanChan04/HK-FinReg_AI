# T3-01 PEA-CAE 成本感知升级 A/B 实验报告（NR-01）

**日期：** 2026-08-05
**论文依据：** [From Naive RAG to Deep Agentic Retrieval](https://arxiv.org/abs/2607.24791)（PEA-CAE: Progressive Evidence Acquisition with Cost-Aware Escalation）
**定位：** 单场景研究原型，**不替换现有 DeepResearch 流程**（现有 workflow 未修改，实验为独立模块）

> **收尾复跑：** 2026-08-07 在最终 108 题基准与已提交语料上复跑；48 场景、0 次升级、claim_recall 0.979/0.979，结果与本报告一致。

## 实验设计

| 组别 | 路径 |
|---|---|
| **对照组（现有）** | 第一轮检索 top_k=6 → gap 补齐第二轮检索 top_k=10（`_retrieve_eval_documents` 确定性路径） |
| **实验组（PEA-CAE）** | 第一轮检索 top_k=6 → 门控决策：**仅当** 预期证据增益 ≥ 0.35 **且** 全文读取成本 ≤ 6（检索调用当量）时，升级为全文读取（最佳文档全 chunk 拼接，模拟全文阅读） |

- **场景数：** 48 个黄金集案例（EXP_051+，覆盖 SFC/HKMA/PCPD、中英、10 种任务类型）
- **评测方式：** 确定性 claim-level 指标（无 LLM 调用，可复现）
- **成本模型：** 全文读取按"检索调用当量"计价（~1k 字符 ≈ 1 次检索调用）

## 实验结果

| 指标 | 对照组 | 实验组 |
|---|---|---|
| claim_recall | 0.979 | 0.979 |
| context_precision | 0.454 | 0.454 |
| evidence units | 480 | 480 |
| **升级决策** | — | **0 escalate / 48 hold** |

- 第一轮检索覆盖率 ≥ 0.5 的场景：**46/48**
- 实验组提升 claim_recall 的场景：**0/48**

## 结论

1. **门控机制工作正确**：48 个场景全部判定"不升级"，与预期一致——现有两轮检索已把 claim_recall 推到 0.979（接近上限），此时全文升级的**预期增益不足 0.35 阈值**（coverage ≥ min_coverage → gain=0）或**成本超限**（监管文档全文通常 >6 检索当量）。
2. **本实验不支持升级**：在该确定性评测路径上，PEA-CAE 的增量价值为 0；这不能外推为所有生产查询都无需成本感知升级。
3. **保留价值**：escalation_gate 模块作为**可复用的成本感知决策组件**保留（12 个单元测试覆盖决策语义），未来若引入真正的全文阅读工具（如 LLM 长文档理解），该门控可直接作为工具路由决策。

## 建议

- **不扩展 PEA-CAE 到更多场景**（实验未显示稳定改善，符合计划"仅当稳定改善才扩展"的退出条件）。
- 模块归档为研究原型，标记 `escalation_gate.py`（含完整测试），供未来全文阅读工具路由参考。
- 若后续语料升级（如加入超长法规文档且第一轮检索覆盖率下降），可复跑本实验验证门控是否开始触发。
